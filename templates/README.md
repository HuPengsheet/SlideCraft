# templates

从 [zarazhangrui/beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates) 原样搬运的 34 套独立 HTML 幻灯片模板（MIT 协议，见 [LICENSE](LICENSE)）。

- 每个目录是一套完整模板：`template.html`（可直接用浏览器打开，方向键翻页）、`template.json`（元数据）、`design.md`（设计说明）。部分模板带自己的 `deck-stage.js`，其余内联。
- [index.json](index.json) 是全部模板的元数据索引。
- 样式内联在各自的 HTML 里，模板之间互不依赖。
- 未搬运上游的 `screenshots/`（约 60MB 预览图）。
