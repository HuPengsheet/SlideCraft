# SlideCraft 模板体系规划

状态：草案，待确认。

## 1. 目标

制作一批风格各异的 HTML PPT 模板。每个风格都需要封面、图表、总结、动效等多种页面。如果每个风格单独做一整套，工作量是"风格数 × 版式数"。本方案把模板拆成三层，使工作量变成"风格数 + 版式数"。

## 2. 三层结构

| 层 | 内容 | 数量 |
|---|---|---|
| 版式层（公用） | 页面的 HTML 结构和布局骨架。只管"放什么、怎么排"，不写具体颜色和字体。 | 一套，约 36 个 |
| 风格层（每个风格一份） | CSS 变量加装饰：字体、配色、圆角、边框、阴影、间距、背景纹理、角标和插画。 | 12 个 |
| 效果层（公用插件） | 打字机、数字滚动、粒子、Glitch、3D 翻转、转场等，用 `data-fx="..."` 属性开启。 | 一套，约 15 个 |

### 工作原理
- 版式只引用变量，例如 `var(--font-display)`、`var(--accent)`、`var(--radius)`、`var(--border)`。换风格文件，同一版式就换了外观。
- 图表颜色也从变量取。
- 版式在需要装饰的位置预留"装饰槽"，由风格层填充。

### 已知限制与对策
1. 风格差异大时，只换变量不够（例如有的风格用斜条纹丝带，有的用圆角卡片）。对策：风格允许对个别版式写少量覆盖 CSS，如 `.theme-x .layout-cover::before { ... }`。大部分版式零覆盖。
2. 装饰是风格的核心。对策：角标、纹理、插画放在风格层，版式只留位置。
3. 前期成本较高：需要先把版式 HTML 设计得足够中性，并统一变量命名。这是一次性投入。

## 4. 公用版式清单（36 个）

加 ★ 的是核心版式（19 个），每个风格必须具备。其余分批补充。

### 结构（7）
- ★ 封面
- ★ 目录
- ★ 章节页
- ★ 大字陈述 / 过渡页
- ★ 总结页
- ★ 结尾 / Q&A
- 空白页（只带风格背景）

### 文字（6）
- ★ 要点列表
- ★ 大字金句
- ★ 大数字强调
- ★ 左右图文
- 全屏背景图加文字
- 双栏 / 三栏文字

### 卡片（4）
- ★ 图标宫格（3、4、6、9 宫格）
- 卡片列表
- Bento 便当盒
- 图片网格（含轮播、画廊）

### 数据（7）
- ★ 柱状图 / 条形图（含排行榜）
- ★ 折线图 / 面积图
- ★ 饼图 / 环形图
- ★ KPI 数字卡片（含进度条）
- 数据表格
- 雷达图
- 散点图 / 气泡图

### 逻辑（9）
- ★ 流程图
- ★ 时间线
- ★ 对比页（A vs B，含前后对比）
- ★ 2×2 矩阵
- 路线图
- 金字塔
- 循环图
- 韦恩图
- 步骤图

### 媒体（3）
- 设备样机
- 代码展示
- 视频嵌入

## 5. 公用效果清单（插件）

效果不算页面类型。每个风格只默认启用 2 到 4 个与调性匹配的，其余按需开启。

| 类别 | 效果 |
|---|---|
| 文字 | 打字机、逐条淡入、文字遮罩揭示、Glitch |
| 数字与图表 | 数字滚动、图表生长、SVG 描边 |
| 背景 | 粒子、渐变流动、霓虹扫光 |
| 交互 | 3D 翻转卡片、鼠标聚光灯、点击展开 |
| 转场 | 淡入淡出、推移、缩放、翻页、Morph |

## 6. 目录结构草案

```
slidecraft/
├── layouts/          # 公用版式，每个一个 HTML 片段
│   ├── cover.html
│   ├── toc.html
│   ├── chart-bar.html
│   └── ...
├── fx/               # 公用效果，每个一个 JS 或 CSS
│   ├── typewriter.js
│   └── count-up.js
├── themes/           # 风格，每个一个文件夹
│   ├── soft-editorial/
│   │   ├── tokens.css      # 变量
│   │   ├── decor.css       # 装饰和少量版式覆盖
│   │   └── theme.json      # mood、tone 等元数据
│   └── ...
└── runtime/deck-stage.js
```

组装一份 deck：选风格、选版式清单，拼出一个完整 HTML。

## 7. 参考

[beautiful-html-templates](../beautiful-html-templates/) 的做法：
- 每个风格是一个独立文件夹：`template.html`（10 到 16 页）、`design.md`、`template.json`。
- 画布固定 1920×1080，用 `<deck-stage>` 组件缩放和翻页（[deck-stage.js](../beautiful-html-templates/runtime/deck-stage.js)）。
- `index.json` 记录每个风格的 mood、tone、occasion、density、scheme，用于按场景挑选。

与本方案的区别：参考库风格间互不依赖，单个风格可做到极致，但新增风格要重做全部版式。本方案风格共享版式，扩展成本低，个性靠覆盖机制补足。
